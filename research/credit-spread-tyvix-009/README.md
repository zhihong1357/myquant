# Credit-spread changes lead Treasury volatility (study 009)

Ninth empirical study in myquant Stage 3, and the second real use of
the Stage 6c scaffold. Research question: does the latest available
BAA10Y credit-spread change predict the next-day TYVIX log change,
beyond TYVIX's own history and the lagged VIX common-factor control?
This is the planner's rank-1 candidate pair after study 008 consumed
BAA10Y→SPX (6a, total score 1.00, adjacent supported edges E0023,
E0026, E0032).

## Design

The predictor is the daily BAA10Y level change in basis points (not
the log return the planner draft names — a spread quoted in
percentage points has no meaningful log return). The target is the
TYVIX daily log change (TYVIX is an index level like VIX). The
expected sign is positive: credit-spread widening reflects credit
stress, which usually accompanies rising rates volatility. The
draft's "positive, out-of-sample component" refers to positive
incremental explanatory power (incremental R-squared above zero), not
to a positive coefficient.

The base model predicts the next-day TYVIX log change from TYVIX's
own lagged log change and the lagged VIX log change; the augmented
model adds the lagged BAA10Y change. The test family has one test
(the primary), Holm-adjusted. Verdict criteria (study 003's three,
no cost gate — TYVIX is not tradable): Holm-adjusted primary p below
0.05, primary partial R-squared at least 0.005, holdout out-of-sample
incremental R-squared above 0. The cost gate is informational only
(gross sign-rule edge, no costs applied, study 003's precedent) and
carries no verdict weight.

The full design lives in `design.json`; the registered spec is in
`hypotheses/registrations/H0014/v1.json`.

Sample windows (21:00 UTC daily closes): train [2003-01-02,
2012-01-01), validation [2012-01-02, 2017-01-01), holdout
[2017-01-02, 2020-05-16), each separated by a one-day purge gap.
Minimum observations: 1000 / 500 / 300. The sample is truncated at
TYVIX's discontinuation (last value 2020-05-15); conclusions cover
2003–2020 only.

### Publication lag (the core PIT issue)

BAA10Y posts about a day later than other FRED series (6b evidence
probe 2026-11-18T21:45Z: BAA10Y latest 2026-11-16, VIXCLS already
2026-11-17). FRED daily values generally post on the next business day
(study 007, N=1), so BAA10Y's effective availability lag is
**2 trading days**: at the close of day t, the latest available
BAA10Y value is dated t-2, and the latest available change is the
change ending t-2. The predictor for the TYVIX log change over t+1
is therefore the BAA10Y change ending at t-2 — a lag-2 predictor by
value date, deliberately. The VIX control carries the standard
1-trading-day lag. Both lags are applied in the trial's panel
construction via the study-007 lagged-changes module
(`myquant.studies.publication_lag.lagged_changes_on_index`); the PIT
store itself records `available_at` equal to the event time (adapter
limitation — see the design's known confounders). The fetch script
re-verifies the posting pattern behaviorally and records the observed
last dates in the manifest.

### Researcher decisions beyond the planner draft

1. Predictor is the level change in basis points, not the log
   return (see above).
2. The universe adds `index:vix` as the common-factor control leg.
   The draft's research question assumes a common-factor control but
   names none; the lab convention (studies 001/003) is a
   contemporaneous third-asset control in the primary test, and VIX
   is the natural volatility common factor. It enters lagged by its
   own 1-trading-day publication lag so it is knowable at the
   forecast time.
3. The BAA10Y predictor is lagged 2 trading days by availability
   (see above).
4. The cost gate is informational only (TYVIX is not tradable; no
   listed TYVIX futures exist), so the verdict takes three criteria
   instead of the draft's four. Study 003's precedent.

## Results

**Verdict: H0014 v1 REJECTED** (trial T0017, ledger record
`4daa54ed5167d4644bbe65ebcff4ef10d5a53cd3ac85c9361e8eaf3e5813d7c5`).
Primary (n = 4,327, HAC max lag 5): coefficient −0.000126 per bp
(wrong sign vs the preregistered positive expectation), SE 0.000401,
p = 0.7540, Holm-adjusted p = 0.7540, partial R² = 6.10e-05 — 82x
below the preregistered minimum effect size of 0.005. The no-factor
upper bound is the same null (p = 0.7387), and the naive lookahead
alignment is also null (p = 0.2020), so the publication lag is not
what killed the effect. Walk-forward: all-OOS incremental R²
−0.000778; holdout (841 rows) −0.000983. The informational cost
assessment reports a gross sign-rule edge of +0.457% per day
(bootstrap p = 0.0375, sign accuracy 54.9%) — direction accuracy
without magnitude accuracy on an untradable index, not a verdict
criterion. All three verdict criteria fail. MDE (partial R², 80%
power) is 0.00181, so the study rules out any effect at or above
~0.0018. Full results, robustness and limitations: the study report
(`docs/studies/credit-spread-tyvix-009.md`).

## Running

From the repo root, with the dev environment installed:

```bash
.venv/bin/python research/credit-spread-tyvix-009/preregister.py
.venv/bin/python research/credit-spread-tyvix-009/fetch_data.py
.venv/bin/python research/credit-spread-tyvix-009/run_trial.py
```

Preregistration must precede any result-level analysis. Coverage
checks (date ranges, bar counts, missing bars) and the publication-lag
verification are the only pre-trial data contact allowed.
