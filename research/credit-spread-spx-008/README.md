# Credit-spread changes lead S&P 500 returns (study 008)

Eighth empirical study in myquant Stage 3, and the first real use of
the Stage 6c scaffold. Research question: does the most recent BAA10Y
credit-spread change available at the close predict the next-day S&P
500 log return beyond the S&P 500's own history and the lagged VIX
common-factor control? This is the planner's rank-1 candidate pair
(6a, total score 1.00, adjacent supported edge E0026).

## Design

The predictor is the daily BAA10Y level change in basis points (not
the log return the planner draft names — a spread quoted in
percentage points has no meaningful log return). The expected sign is
negative: spread widening predicts weaker next-day SPX returns. The
draft's "positive, out-of-sample component" refers to positive
incremental explanatory power (incremental R-squared above zero), not
to a positive coefficient.

The base model predicts the next-day SPX log return from SPX's own
lagged return and the lagged VIX log change; the augmented model adds
the lagged BAA10Y change. The test family has one test (the primary),
Holm-adjusted. Verdict criteria (study 001's four): Holm-adjusted
primary p below 0.05, primary partial R-squared at least 0.005,
holdout out-of-sample incremental R-squared above 0, net daily edge
after the SPY round-trip spread cost positive.

The full design lives in `design.json`; the registered spec is in
`hypotheses/registrations/H0013/v1.json`.

Sample windows (21:00 UTC daily closes): train [2003-01-02,
2020-01-01), validation [2020-01-02, 2024-01-01), holdout
[2024-01-02, 2026-11-18), each separated by a one-day purge gap.
Minimum observations: 1000 / 500 / 300.

### Publication lag (the core PIT issue)

BAA10Y posts about a day later than other FRED series (6b evidence
probe 2026-11-18T21:45Z: BAA10Y latest 2026-11-16, VIXCLS/VXNCLS/DGS10
already 2026-11-17). FRED daily values generally post on the next
business day (study 007, N=1), so BAA10Y's effective availability lag
is **2 trading days**: at the close of day t, the latest available
BAA10Y value is dated t-2, and the latest available change is the
change ending t-2. The predictor for the SPX return over t+1 is
therefore the BAA10Y change ending at t-2 — a lag-2 predictor by
value date, deliberately. The VIX control carries the standard
1-trading-day lag. Both lags are applied in the trial's panel
construction via the study-007 lagged-changes module
(`myquant.studies.publication_lag.lagged_changes_on_index`); the PIT
store itself records `available_at` equal to the event time (adapter
limitation — see the design's known confounders). The fetch script
re-verifies the posting pattern behaviorally and records the observed
last dates in the manifest.

### Researcher decisions beyond the planner draft

1. Predictor is the level change in basis points, not the log
   return (see above).
2. The universe adds `index:vix` as the common-factor control leg.
   The draft's research question assumes a common-factor control but
   names none; the lab convention (studies 001/003) is a
   contemporaneous third-asset control in the primary test, and VIX
   is the natural equity-market risk proxy. It enters lagged by its
   own 1-trading-day publication lag so it is knowable at the
   forecast time.
3. The BAA10Y predictor is lagged 2 trading days by availability
   (see above).

## Results

**Verdict: H0013 v1 REJECTED** (trial T0016, ledger record
`5e2ca06ab5c3c417df84dac18f71e435ec10114411c1c867d4beb10d98426170`).
Primary (n = 5,957, HAC max lag 5): coefficient +1.80e-05 per bp (wrong
sign vs the preregistered negative expectation), SE 1.35e-04, p = 0.8935,
Holm-adjusted p = 0.8935, partial R² = 2.19e-05 — 228x below the
preregistered minimum effect size of 0.005. The no-factor upper bound is
the same null (p = 0.8924), and the naive lookahead alignment is also null
(p = 0.3665), so the publication lag is not what killed the effect.
Walk-forward: all-OOS incremental R² −0.00339; holdout (716 rows)
+0.000146. Cost gate: net daily edge +0.0106%, bootstrap 95% CI
[−0.0446%, +0.0719%], p = 0.7236 — statistically zero. Two of four
verdict criteria pass (holdout OOS R² > 0, net edge > 0), both by a hair
on noise; the two decisive criteria fail by orders of magnitude. MDE
(partial R², 80% power) is 0.00132, so the study rules out any effect at
or above ~0.0013. Full results, robustness and limitations: the study
report (`docs/studies/credit-spread-spx-008.md`).

## Running

From the repo root, with the dev environment installed:

```bash
.venv/bin/python research/credit-spread-spx-008/preregister.py
.venv/bin/python research/credit-spread-spx-008/fetch_data.py
.venv/bin/python research/credit-spread-spx-008/run_trial.py
```

Preregistration must precede any result-level analysis. Coverage
checks (date ranges, bar counts, missing bars) and the publication-lag
verification are the only pre-trial data contact allowed.
